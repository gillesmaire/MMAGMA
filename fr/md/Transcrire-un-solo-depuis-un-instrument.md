# Transcrire un solo depuis un enregistrement{.unnumbered}

## Objectif{.unnumbered}
Pour ceux qui jouent un solo depuis une partition la retranscription en notes n'est pas très 
difficile. 

Pour les musiciens qui jouent leur solo d'oreille, il peut être intéressant de capter les notes
à partir d'un enregistrement. C'est ce qu'explique cette annexe.

## Le site Frequency detector{.unnumbered}

Le site Frequency detector est capable de trouver les accords mais il est également l'un des seuls
à permettre de capturer un solo et d'en restituer les notes. 

## Mode opératoire{.unnumbered}

Pour capturer les notes : 

1. Aller sur le site https://frequencydetector.com/music-note-detector/
2. Appuyer sur le bouton *Start Listening* et choisissez la source d'enregistrement. Il n'est pas nécessaire de brancher un micro de haute qualité, le micro d'un ordinateur portable ou d'une caméra suffit amplement.
3. Jouer
4. Une fois la séquence capturée, appuyez sur le bouton *Stop* 
5. Les notes jouées apparaissent entourées par des rond dans la rubrique *Notes History*
6. Selectionner à la souris toutes ces notes et copier les dans votre fichier MMA : 

~~~mma
G#3 
A#3
B3
D#4
G4
C#2
A#3
~~~

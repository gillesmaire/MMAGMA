# Transcrire un solo depuis un enregistrement{.unnumbered}

## Objectif{.unnumbered}

Pour ceux qui jouent un solo depuis une partition la retranscription en notes n'est pas très 
difficile. 

Ceux qui utilisent un clavier MIDI peuvent enregister leur piste en MIDI et changer juste 
l'instrument dans MMA.

Pour les musiciens qui jouent leur solo d'oreille, comme le ferait un guitariste, il peut être
intéressant de capter les notes à partir de son instrument et de les transcrire en MIDI pour les
faire jouer dans un autre instrument. C'est ce qu'explique cette annexe.

On peut aussi objecter qu'il est peut être plus simple de positionner l'enregistrement directement dans un 
logiciel comme Ardour. C'est vrai, mais quelqu'un qui joue d'oreille sur une guitare a peut être envie de 
voir ce que donne son solo sur une trompette ou tout autre instrument. 

C'est ce que permet cette annexe.

## Le site Frequency detector{.unnumbered}

Le site Frequency detector est capable de trouver les accords mais il est également l'un des seuls
à permettre de capturer un solo et d'en restituer les notes. 

## Mode opératoire{.unnumbered}

Pour capturer les notes : 

1. Aller sur le site https://frequencydetector.com/music-note-detector/
2. Appuyer sur le bouton *Start Listening* et choisissez la source d'enregistrement. Il n'est pas nécessaire de brancher un micro de haute qualité, le micro d'un ordinateur portable ou d'une caméra suffit amplement.
3. Jouer
4. Une fois la séquence capturée, appuyez sur le bouton *Stop* 
5. Les notes jouées apparaissent entourées par des rond dans la rubrique *Notes History*
6. Selectionner à la souris toutes ces notes et copier les dans votre fichier MMA : s

~~~mma
G#3 
A#3
B3
D#4
G4
C#2
A#3
~~~
